## 自動テストで確認する範囲

- QR画像の生成
- 一覧ページや動画案内だけではファイルを自動取得しないこと
- 画像と動画で異なる保存案内を表示すること
- MP4/MOV/M4VのMIME、ダウンロード応答、ファイル名
- 日本語・絵文字・HTML特殊文字を含むファイル名
- HTTP Rangeによる部分取得
- 不正な認証トークンの拒否
- 通信プロトコルの暗号化処理・ループバック送受信

テストの動画データは転送処理の検証用です。実際に再生できる動画、Safariの画面、iOS共有メニューを自動テストで検証しているわけではありません。
