# トラブル対応

## QRを読んでもSafariが開けない

- WindowsとiPhoneが同じ通常Wi-Fiか確認する
- ゲストWi-Fiを避ける
- ルーターの「AP isolation」「プライバシーセパレーター」「端末間通信禁止」を無効にする
- Windows Defender Firewallが表示されたら、プライベートネットワークだけを許可する
- VPNを一時的に切って試す

## 「ページを開けません」と表示される

- QRは30分で失効するため、Windowsで閉じて右クリックから作り直す
- 最初に別の端末でQRを開くと、その端末へ固定されるため作り直す
- Windowsのネットワーク設定が「パブリック」の場合は「プライベート」へ変更する

## 右クリックに表示されない

- Windows 11でMSIXが導入済みか確認する
- LocalBridge設定を一度開く
- エクスプローラーを開き直す。必要ならサインアウトして戻る
- `その他のオプション`ではなく、新しい右クリック欄を確認する

## 「iPhoneに送る」を押してもQRが出ない

0.3.1以前では、常駐アプリが停止していて起動先の登録がない、または更新前の場所を指していると、右クリックから起動できない問題がありました。0.3.2では、右クリック機能と一緒にインストールされたアプリを直接起動するよう修正しています。設定画面を先に開かなくても送信を始められます。

0.3.2以降でも出ない場合は、既に開いているQR画面を確認してください。QR画面は1件ずつ表示されます。Windowsの通知やLocalBridgeの診断ログにも、ネットワーク接続やファイルが見つからないなどの理由が表示されます。

## 写真アプリへ入らない

「写真アプリに保存する」は自動保存ではありません。写真はプレビュー画面から「画像を保存」を選びます。

### 動画の共有に「ビデオを保存」がない

動画を埋め込んだWebページの共有では、ページのURLが共有され、動画の保存項目が出ない場合があります。次の順番で動画ファイル自体を共有します。

1. 「写真アプリに保存する」→「動画をダウンロード」を押す
2. ダウンロード完了後、Safariのアドレス欄付近の`↓`→「ダウンロード」で動画を開く
3. 開いた動画の共有ボタン`□↑`を押し、メニューを下へスクロールして「ビデオを保存」を選ぶ

見つからない場合は、「ファイル」アプリの「最近使った項目」やダウンロード先で動画を長押しし、「共有」→「ビデオを保存」を試してください。iOSのバージョンや動画形式によって表示は異なります。再生できない動画はiPhone対応の形式への変換が必要な場合があります。拡張子を変更するだけでは変換されません。

ダウンロード完了まではWindowsのQR画面を開いたままにしてください。ダウンロードの場所については[Appleの案内](https://support.apple.com/ja-jp/102440)も参照できます。

## Filesへ入らない

Safariのダウンロード表示を確認します。保存場所はiPhoneの「設定 → Safari → ダウンロード」で指定された場所です。

## エラー調査

Windows設定の「診断情報を書き出す」でZIPを作れます。ファイル本文、QR URL、認証トークンは含みません。
